# KT №4 — Работа с Redux

Реализация корзины товаров на React + Redux.

## Запуск

```bash
npm install
npm run dev
```

## Функционал

- Отображение товаров из `defaultState`
- Кнопки `+` / `−` для изменения количества каждого товара
- Ограничение count от 1 до 25
- Удаление товара при уменьшении count до 0
- Добавление нового товара через `prompt()`
